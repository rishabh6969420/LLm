# AIML Custom LLM & Research Assistant

A complete repository for building, training, and fine-tuning Large Language Models (LLMs), designed specifically for AI/ML study, research, and hands-on experimentation.

## 🚀 Repository Roadmap
- **`from_scratch/`**: Pure PyTorch implementation of a Decoder-only Transformer (BPE Tokenizer, RoPE, RMSNorm, Multi-Head Attention, Training & Inference).
- **`fine_tuning/`**: Parameter-Efficient Fine-Tuning (PEFT / LoRA / QLoRA) on modern open-weights models (e.g., Qwen 2.5, Llama 3, Gemma 2).
- **`assistant_rag/`**: Personal AI/ML Study & Research Assistant with RAG (Retrieval-Augmented Generation) for papers, notes, and code.
- **`notebooks/`**: Step-by-step interactive notebooks for learning and experimentation.
